# 源格式

全书一个 YAML 文件：`laozi.yaml`。

一种语法、一棵树。章、对照、白文、校记、今译、按语、繁简都在这里。

## 会进成品的字符串

下文称这种值为 **文本**。只允许两种形状：

```yaml
# 繁简同形
title: 上德不德

# 繁简不同形
title:
  hant: 大道廢
  hans: 大道废
```

规则：

1. 值是字符串 → 繁体、简体都用这一份。
2. 值是对象 → 必须恰好有 `hant` 与 `hans`，且都是字符串。少一个、多一个、或夹杂别的键，都是错误。
3. 空内容只写 `""`（视字段是否允许空，见各键）。不要用 `null`，也不要用空对象 `{}` 表示「繁简相同的空」。`readings` 的残缺、总说的 `n` / `choice` 另论，见校记。

`hant` / `hans` 来自 ISO 文字代码（`zh-Hant` / `zh-Hans`），指文字，不指地区。

## `|` 是什么

`|` 是 YAML 的字面块：从下一行到本块结束，换行、空行、冒号都原样保留。

**白文、校记理由、今译、按语** 一律用 `|`，即使目前只有一行。这样后来加行不必改写法，也不必和含冒号的短句搏斗。

章题、lemma、各本异文等短标签：同形写一行即可；不同形再拆 `hant` / `hans`，一般不必 `|`。

```yaml
baiwen:
  hant: |
    大道廢〔1〕，有仁義。
  hans: |
    大道废〔1〕，有仁义。

reason: |
  帛甲此句残。今从王弼。
```

今译、按语在排版前按 **Markdown** 渲染（可有段落、列表、章内链接）。`|` 只负责把原文装进 YAML；渲染是构建的事。白文、lemma、异文不当 Markdown 渲染。

## 整书骨架

```yaml
meta:
  title: 老子

witnesses:
  - 王弼
  - 帛甲
  - 帛乙
  - 北大
  - 郭店

chapters:
  - id: de-01
    seq: 1
    pian: 德经
    title: 上德不德
    maps:
      received:
        - { from: 38, to: 38 }
      mawangdui:
        - { from: 1, to: 1 }
      beida: []
      guodian: []
    baiwen: |
      上德不德〔1〕，是以有德〔2〕。
    jiaokan:
      - n: 1
        lemma: 上德不德
        readings:
          王弼: 上德不德
          帛甲: null
        choice: 王弼
        reason: |
          帛甲此句残。今从王弼。
    yiwen: |
      最高的德，不自居为德，所以才有德。
    anyu: |
      此章论上德与下德之辨。
```

顶层只允许 `meta`、`witnesses`、`chapters`。

## `meta`

| 键 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `title` | 文本 | 是 | 书题，进封面、工具栏、页签与页眉 |

以后若有副题、作者署名，再在 `meta` 下加键，并同步改校验。

## `witnesses`

字符串列表。全书用到的本子，名称写死在这里。

校记里 `readings` 的键、`choice` 的值，必须是这个列表中的一项。未登记的本子名，校验失败。

顺序即校记里列举异文的默认顺序。

## `chapters`

列表。**列表顺序就是书中顺序**（德经在前）。`seq` 必须从 1 连续递增，并与列表位置一致，防止拖动条目后忘了改号。

### 每章必有的键

| 键 | 类型 | 说明 |
| --- | --- | --- |
| `id` | 字符串 | 稳定标识，全书唯一。一经写出不要为改题而改 `id`。只允许小写字母、数字与连字符，如 `de-01`、`dao-01` |
| `seq` | 正整数 | 本书章次，从 1 起 |
| `pian` | `德经` 或 `道经` | 所属篇 |
| `title` | 文本 | 章题 |
| `maps` | 对象 | 他本对照 |
| `baiwen` | 文本 | 白文，含注号 |
| `jiaokan` | 列表 | 校记，可为空列表 |
| `yiwen` | 文本 | 今译；暂无可写 `""` |
| `anyu` | 文本 | 按语；暂无可写 `""` |

多一个未知键，校验失败，以免拼错的键被默默丢掉。

### `maps`

四个键都必须出现。无对应则 `[]`，不要省略键。

| 键 | 对照 |
| --- | --- |
| `received` | 通行本（王弼系章次） |
| `mawangdui` | 马王堆帛书章次（按帛书自身分章） |
| `beida` | 北大汉简章次 |
| `guodian` | 郭店简；无则空 |

每一项：

```yaml
- { from: 38, to: 38 }      # 对应他本一整章
- { from: 18, to: 19 }      # 本书一章含他本连续数章
```

`from`、`to` 为正整数，且 `from <= to`。

本书一章对应他本不相邻的多段，就写多条。他本一章被拆进本书两章，各章各自写自己的那段（可 `from` `to` 相同，必要时以后再加 `note` 文本说明；**暂不设 `note`，有需要再开**）。

### `jiaokan` 一条

| 键 | 类型 | 说明 |
| --- | --- | --- |
| `n` | 正整数或 `null` | 与白文 `〔n〕` 对应；`null` 表示不挂白文的总说 |
| `lemma` | 文本 | 所校字句。`n` 为 `null` 时可写 `""` |
| `readings` | 对象 | 各本用字。键必须是 `witnesses` 中的名 |
| `choice` | 字符串或 `null` | 今从哪一本；必须是 `witnesses` 中的名。总说可 `null` |
| `reason` | 文本 | 当前判断的理由。用 `\|` |

`readings` 的值是文本，或 `null`（残、无此句、未见）。不必为每个本子都写一项；没写的视为「本条不列该本」，不是「与今从相同」。

一条里不要出现未知键。

## 注号校验

对每一章：

1. 从白文的繁、简**分别**抽出 `〔` 纯数字 `〕`，得到注号列表。
2. 繁、简抽出的注号序列必须相同（数字、顺序都要一样）。否则报该章 `baiwen`。
3. 注号为大于 0 的整数，一章内不重复。
4. `jiaokan` 里 `n` 非空者，必须与白文注号一一对应：白文有的，校记要有；校记有的，白文要有。
5. `n: null` 的总说可以有 0 或 1 条。多于一条报错（总说请写在同一条 `reason` 里）。

补字 `〔德〕` 不参与注号校验。

## 解析失败时怎么报

YAML 缩进错会导致**整文件解析失败**。这是单文件方案唯一严重的问题。

分两层报错，禁止只丢一行库函数原文了事：

1. **语法层**（缩进、制表符、未结束的引号等）  
   报文件行号、列号，并尽量指出「出错位置大约在 `chapters` 第几项附近」（按已扫到的最后一个 `id` 或列表下标）。例如：  
   `laozi.yaml:214:3 语法错误，上一章已读到 id=de-07（seq 7）。请检查缩进。`
2. **schema 层**（键名、类型、注号、对照、witnesses）  
   必须报到章与键：  
   `第 3 章（id=de-03）jiaokan[1].readings：未登记的本子名「傅奕」`  
   `第 3 章（id=de-03）baiwen：简体注号为 1,2,4，繁体为 1,2,3`

没有 `id` 的章（schema 还没读到或 `id` 本身坏了）用「第 N 章（列表第 N 项）」指称，N 从 1 计。

## 暂不写入源的东西

这些由构建决定，不要出现在 `laozi.yaml`：

- 横排 / 竖排
- 现代 / 线装
- 只出白文还是详本
- 字体、纸张、页眉

## 以后若文件太大

schema 不变，把 `chapters` 拆到 `chapters/*.yaml` 再拼回来即可。现在不拆。
